# 단축키 도우미

클립스튜디오, 포토샵 등 그래픽 툴에서 한글 입력 상태로 인한 단축키 씹힘 문제를 해결하고, 프로그램마다 CapsLock·Tab 키를 원하는 대로 바꿔 쓸 수 있게 해주는 트레이 앱입니다.

_본 프로그램은 AI의 도움을 받아 작성했습니다._

---

## 제작 배경

[륜님의 오토핫키 한영전환 스크립트](https://iamlyun.tistory.com/entry/%EA%B0%84%ED%8E%B8-%ED%95%9C%EC%98%81%EC%A0%84%ED%99%98-%EC%8A%A4%ED%81%AC%EB%A6%BD%ED%8A%B8?category=940609)를 기반으로 제작하였습니다. 해당 스크립트는 윈도우 11 환경으로 넘어오면서 별도 설정 없이는 동작하지 않게 되었고, 이를 계기로 C++ Win32 네이티브 앱으로 새로 구현하였습니다.

> **륜**님의 원본 스크립트는 **원사운드** 님의 포토샵 한글 단축키 스크립트를 기반으로 작성되었습니다.

처음에는 자동 한영 전환만 지원하는 작은 프로그램이었지만, 그래픽 작업에서 자주 쓰이지 않는 CapsLock키, 오작동이 잦은 Tab 키 차단 혹은 리매핑 기능이 추가되고 프로그램마다 설정을 완전히 다르게 가져갈 수 있게 업데이트했습니다.

## 기능

### 자동 한영 전환

마우스가 움직일 때마다 입력 상태를 감지하여 한글이면 자동으로 영문으로 전환합니다. 말풍선 입력 등 한글이 필요한 경우 트레이 아이콘을 더블클릭하거나 트레이 메뉴에서 해당 프로그램의 자동 전환을 끌 수 있습니다.

### CapsLock 키 / Tab 키 리매핑

잘 사용하지 않는 CapsLock 키나 작업 중 실수로 누르기 쉬운 Tab 키를 프로그램 안에서 다른 키(F13~F24 등)로 대체하거나 아예 입력을 차단할 수 있습니다. 물리 키보드에 없는 F13 이상의 키로 매핑해두면 다른 단축키와 겹칠 일이 거의 없으며, 그래픽 툴의 단축키 설정 화면에서 이 키를 원하는 동작에 자유롭게 배정할 수 있습니다.

### 프로그램별 완전 독립 설정

등록한 프로그램 개별로 자동 영어 전환·CapsLock 리맵·Tab 리맵을 설정할 수 있습니다. 클립스튜디오에서는 Tab 리맵을 켜두고 포토샵에서는 꺼두는 식으로, 프로그램마다 완전히 다른 조합을 쓸 수 있습니다.

### 대상 프로그램 관리

트레이 메뉴 → **대상 프로그램 등록/수정...** 에서 프로그램을 등록·삭제하고 각 프로그램의 설정을 표(리스트뷰) 형태로 한눈에 확인·수정할 수 있습니다.

- 실행 중인 프로세스 목록에서 골라 추가하거나, 프로세스 이름을 직접 입력해 추가할 수 있습니다.
- 목록의 각 행은 `프로그램명 | 자동 영어 전환 | CapsLock 리맵 | Tab 리맵` 네 개 열로 구성되며, 초록/빨강 점(●)으로 켜짐·꺼짐을, 리맵이 켜져 있으면 어떤 키로 매핑되는지(또는 "차단")를 함께 보여줍니다.
- 목록에서 프로그램을 더블클릭하거나, 우클릭 메뉴 또는 **프로그램 설정** 버튼으로 그 프로그램의 세부 설정을 열 수 있습니다.
- **삭제** 버튼(또는 우클릭 - 삭제)으로 등록을 제거할 수 있으며, 실수 방지를 위해 확인 창이 한 번 뜹니다.
- explorer, dwm 등 시스템 프로세스는 실행 중 프로세스 목록에 뜨지 않아 실수로 등록하는 일을 막아줍니다(직접 입력으로는 등록 가능).

> ⚠️ **주의:** 온라인 게임을 등록할 경우 안티치트 프로그램에 감지될 수 있습니다. 용도 외 사용으로 발생하는 문제에 대해서는 책임지지 않습니다.

### 윈도우 시작 시 자동 실행

트레이 메뉴에서 토글 한 번으로 윈도우 부팅 시 이 프로그램이 자동으로 실행되도록 설정할 수 있습니다. 관리자 권한 없이 현재 사용자 계정에만 등록됩니다.

## 트레이 메뉴 사용법

- **더블클릭**: 현재 프로그램의 자동 영어 전환을 즉시 토글합니다.
- **우클릭**: 아래와 같은 메뉴가 뜹니다.

```
현재 프로그램: clipstudiopaint
─────────────────
✓ 자동 영어 전환
✓ Capslock 리맵 (F13)
  Tab 리맵 (차단)
─────────────────
대상 프로그램 등록/수정...
✓ 윈도우 시작 시 자동 실행
─────────────────
종료
```

메뉴 상단에는 지금 이 메뉴의 조작이 적용될 프로그램 이름이 표시됩니다. 등록되지 않은 프로그램을 보고 있을 때는 마지막으로 확인된 등록 프로그램 기준으로 표시됩니다.

## 설정 파일

실행 파일과 같은 폴더에 `config.ini`가 자동 생성됩니다. 프로그램마다 한 줄씩, 이름과 전체 설정이 함께 저장됩니다.

```ini
Profile=clipstudiopaint|ae=1|remap=1|remapkey=F13|tab=1|tabkey=F14
Profile=photoshop|ae=1|remap=0|remapkey=F13|tab=0|tabkey=0
Profile=affinity|ae=1|remap=0|remapkey=F13|tab=0|tabkey=0
```

과거 버전(전역 설정 + 프로그램별 예외)의 `config.ini`가 있는 상태로 실행하면, 그 시점의 전역값을 각 프로그램에 그대로 복사해 새 형식으로 자동 변환됩니다.
